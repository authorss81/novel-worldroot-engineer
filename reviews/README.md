## THE CHECK A REVIEW MUST RUN, WHICH IS NOT A READING PASS, AND WHY IT IS HERE

**A CHAPTER PRINTED ONE HUNDRED AND NINETY-FIVE THREE TIMES, DERIVED IT TWICE BY ITS OWN ARITHMETIC, PRINTED ONE HUNDRED AND FIFTY-FIVE THIRTY-SIX LINES BELOW ALL OF IT, AND PASSED A BATCH REVIEW, A CLOSE, A REVIEW FIX PASS AND A SECOND CLOSE PASS. NOBODY SAW IT BECAUSE EVERY PASS READ THE PAGE. THE CHECK THAT FINDS IT IS MECHANICAL AND IT IS FOUR COMMANDS.**

**ONE. THE BAND, PER CHAPTER, AND IT IS RUN AFTER EVERY PROSE EDIT AND NEVER BEFORE.**

```
cd workspace && for f in volume-*/batch-*/chapter-*.md; do echo "$(wc -w < $f) $f"; done | sort -rn | head -12
```

**TWO. THE TOTALS, AND THEY MUST SUM TO THE MANUSCRIPT WITH NO RESIDUAL.**

```
cd workspace && t=0; for v in volume-0*; do s=$(cat $v/batch-*/chapter-*.md | wc -w); n=$(ls $v/batch-*/chapter-*.md | wc -l); echo "$v $s $n"; t=$((t+s)); done; echo "TOTAL $t $(ls volume-*/batch-*/chapter-*.md | wc -l)"
```

**THREE. THE MECHANICAL PROPERTIES, PER FILE, WHICH RETURN ZERO OR THE PASS DID NOT RUN.**

```
cd workspace && for f in volume-*/batch-*/chapter-*.md; do
  a=$(LC_ALL=C grep -c '[^ -~]' $f); b=$(grep -c '[“”‘’–—]' $f); c=$(grep -c ' $' $f)
  d=$(awk 'BEGIN{p=0;c=0} /^$/{if(p){c++};p=1;next}{p=0} END{print c}' $f)
  q=$(grep -o '"' $f | wc -l); m=$(grep -o '\*\*' $f | wc -l)
  [ $a -eq 0 ] && [ $b -eq 0 ] && [ $c -eq 0 ] && [ $d -eq 0 ] && [ $q -eq 0 -o $((q%2)) -eq 0 ] || echo "FAIL $f a=$a b=$b c=$c d=$d"
done
```

**FOUR. THE DERIVE-AND-COMPARE CHECK, WHICH IS THE ONE THAT MATTERS AND THE ONLY ONE NOBODY HAS RUN, AND IT IS NOT A SCRIPT BECAUSE `scripts/` IS CONTROLLER-OWNED AND NO WRITER PHASE MAY WRITE THERE.** For every series a chapter names, extract the figures it prints and recompute them from the series' own rule instead of reading them off the page. The rules that carry in this manuscript are few enough to write out: **the third launder's count is day minus four hundred and fifty; the boards are day minus sixty-six and the March's tin day minus nineteen; the ninth-day returns are a nine-day cycle rising by eleven; the aggregate sentence is day minus four hundred and fifty-two, written on day minus four hundred and fifty-three mornings out of day minus four hundred and fifty-one; a day is an ordinal and the ordinal follows from the day number and the month table, so any *of last month* is checkable against the day the chapter itself prints.** Where a chapter prints a figure that is deliberately outside its series, the check must ask the second question before it reports anything: **would repairing it cost something the chapter promised to keep?** One hundred and twenty-seven on the back of a sheet at `chapter-0285.md:37` is a plant, and a check that reports it as a slip will take an open thread out of the book.

**AND THE RULE THE COMMANDS SERVE, WHICH IS THE ONLY ONE: EVERY FIGURE IS RE-MEASURED AFTER THE PROSE MOVES AND NOT BEFORE, AND A FIGURE WRONG IN TWO FILES THAT AGREE WITH EACH OTHER IS THE MOST DANGEROUS WAY FOR A NUMBER TO BE WRONG.**
